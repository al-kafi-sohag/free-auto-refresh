Use case

Follow an auction to the last second

Not every auction page updates itself. A short refresh interval keeps the current bid in front of you when it matters.

Add to Chrome Add to Firefox

Fresh bids

Reload every few seconds in the closing minutes.

Alert on a new bid

Watch the current-bid element and get notified when it moves.

Keeps your place

Scroll position is restored so the bid box stays in view.

How to set it up

  1. Open the auction listing.
  2. Set Min and Max to 5 for the final minutes.
  3. Switch on Keep scroll position.
  4. Optionally watch the bid element with Stop when content changes.

Suggested settings

Min / Max5 to 10 seconds near the end
Keep scroll positionOn
Pause while typingOn, so your bid is not wiped

Type your bid safely

Leave Pause while typing on. If a refresh comes due while you are entering an amount, it waits.

Questions

Is refreshing allowed on auction sites?

Rules differ. Short bursts are usually fine, but check the site's terms before refreshing rapidly for long periods.
