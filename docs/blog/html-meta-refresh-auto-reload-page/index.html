Auto refresh a page with HTML.

If you build the page yourself, you do not need an extension. One line of HTML will reload it on a timer. Here is how, plus the catch with each method.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

Method 1: the meta refresh tag

Add this inside the <head> of the page. The number is the time in seconds.

<meta http-equiv="refresh" content="30">

That reloads the page every 30 seconds. To send visitors to another page after a delay, add a URL:

<meta http-equiv="refresh" content="5; url=https://example.com/">

Method 2: JavaScript

A script gives you more control, such as reloading only when the tab is visible.

setInterval(function () {
  if (!document.hidden) location.reload();
}, 30000);

The number is in milliseconds, so 30000 is 30 seconds.

The catches

  • A meta refresh reloads even while someone is typing in a form, which can wipe what they entered.
  • It cannot stop when something changes, and it cannot tell you anything. It just reloads.
  • Accessibility guidance advises against forced refreshes on pages people read, because it can interrupt screen readers and keyboard users.
  • It only works on pages you can edit.

When an extension is the better tool

If the page belongs to someone else, you cannot add a tag to it. And if you are working on your own page, an extension lets you turn the reload on and off without editing code. Auto reload for developers shows how, and Smart pause holds the reload while you type.

Good to know

Questions, answered.

What is the shortest meta refresh time?

You can use 1, or even 0, but a fast reload loop is hard on the server and on the visitor. Use the longest time that is useful.

Is meta refresh bad for SEO?

A timed reload with a long delay is usually harmless, but an instant redirect with a meta refresh is a weak redirect. Use a server-side 301 redirect for moved pages.

Can I use this on a page that is not mine?

No, you need to be able to edit the page. For other people's pages, use a browser extension instead.
