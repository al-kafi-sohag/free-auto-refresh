Auto refresh WordPress while you edit.

Switching tabs and pressing F5 after every change is slow. Let one tab reload on its own while you edit in another, and see the result as soon as you save.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

The setup

  1. Open your site's front end in one tab, and the editor or Customizer in a second tab.
  2. In the front-end tab, open Free Auto Refresh and set an interval of 10 to 30 seconds.
  3. Press Start. The tab reloads on its own. Save your changes in the editor and glance at it.

Keep your place on a long page

Turn on Keep scroll position so each reload returns to the same spot, instead of jumping to the top.

Skip the manual reloads

Bypass the cache

Caching plugins and CDNs can show an old copy of the page. Turn on the hard reload option so the browser skips its own cache. If you still see old content, purge the plugin's cache from the WordPress admin bar.

Do not refresh the editor

Never put the timer on the editor tab. A reload can lose unsaved work. If you must watch an admin screen, enable Smart pause, which holds off while you are typing.

Stop it when you finish

Press Stop, or use a limit such as 30 minutes so it never runs overnight. See the WordPress use case for more.

Good to know

Questions, answered.

Will it refresh the editor and lose my work?

Only if you start it there. Put the timer on the front-end tab, not the editor.

Why do I still see the old page?

A caching plugin or CDN. Turn on hard reload and purge the plugin's cache.

Does it work with page builders?

Yes, for the front-end preview tab. Page builders often have their own live preview too.
