Chrome Ctrl+F5 and force reload.

People say force refresh, hard reload and Ctrl+F5 as if they were different things. In Chrome they are the same family of shortcut. This page sorts them out.

Al Kafi SohagNov 18, 20262 min read

What Ctrl+F5 does in Chrome

Ctrl + F5 reloads the current page and tells Chrome to ignore its cached copy. Chrome then downloads the page's files again from the website.

Every force reload shortcut

  • Ctrl + F5 on Windows and Linux
  • Ctrl + Shift + R on Windows, Linux and ChromeOS
  • Command + Shift + R on a Mac
  • Shift + click on the reload button on any system

They all do the same job, so use whichever your keyboard handles easily.

Laptop keyboards

On many laptops the F-keys control brightness or volume unless you hold Fn. If Ctrl + F5 does nothing, try Ctrl + Fn + F5, or use Ctrl + Shift + R, which needs no function key.

Force reload vs regular reload

A regular reload (F5) may still use cached files. A force reload never does for that load. If you are checking a change you just published, always force reload.

When force reload is not enough

If the page still shows old content, the old version may be held by the website's own server or a CDN. In that case reloading again in your browser will not help. Wait a few minutes, or ask the site owner to clear their cache.

Good to know

Questions, answered.

Is Ctrl+F5 the same as Ctrl+Shift+R?

In Chrome, yes. Both reload the page without using the cached copy.

Why does Ctrl+F5 not work on my laptop?

Your F-keys may need the Fn key. Use Ctrl + Shift + R instead.

Does force reload clear my history?

No. It does not touch history, cookies or passwords.
