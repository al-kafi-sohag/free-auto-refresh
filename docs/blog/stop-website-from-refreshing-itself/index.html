Troubleshooting

Stop a website from refreshing itself.

When the site itself reloads the page, no extension setting will fix it. First, understand how sites do it. Then you can pick the right workaround.

Al Kafi SohagNov 18, 20262 min read

How a website refreshes itself

Two common methods. A meta refresh tag in the page's code tells the browser to reload after some seconds. A script calls a reload function on a timer. Both run without you doing anything.

Firefox: you can block it

Type about:config in the address bar, search for accessibility.blockautorefresh and set it to true. Firefox will then ask before a page refreshes or redirects itself.

Chrome: no built-in switch

Chrome has no setting that blocks a site's own refresh. These workarounds help:

  • Look for a pause live updates or auto refresh off toggle on the site itself.
  • Open the page in Reader mode or a print view, which does not reload.
  • Turn off JavaScript for that one site in Site settings. This stops script-based reloads, but not meta refresh tags, and it can break the page.

If it is your own extension

Click the extension's icon and press Stop. For Free Auto Refresh, press Alt + Shift + R or the stop button on the on-page counter. Smart pause can also hold off while you type, so a refresh never wipes a form.

When the cause is not the site

Tab sleeping and extensions can look the same. If you are not sure, read the eight common causes first.

Good to know

Questions, answered.

Can Chrome block auto refresh?

Not with a built-in setting. Firefox can, through accessibility.blockautorefresh.

What is a meta refresh?

An HTML tag that tells the browser to reload or redirect after a set number of seconds.

Will turning off JavaScript stop it?

It stops script-based refreshes but not meta refresh tags, and it may break the page.
