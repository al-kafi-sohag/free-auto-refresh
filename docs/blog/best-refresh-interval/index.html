The best refresh interval for the job.

There is no single right interval. It depends on how fast the page changes and how much the website tolerates. Here is a simple way to choose.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

Start from how fast the page changes

  • Every 5 seconds: live scores, an auction in its last minutes, a deploy or build you are watching.
  • Every 30 seconds: a queue, a status page, an order that is about to ship.
  • Every 1 to 2 minutes: stock and price pages, ticket sales, restock checks.
  • Every 5 minutes or more: job boards, results pages, forms that rarely change.

Why shorter is not always better

Very short intervals add load to the website. Some sites respond by slowing you down or showing an error. A longer interval catches nearly every change anyway, because most pages do not change second by second.

Use a range instead of a fixed beat

With random intervals you set a minimum and a maximum, for example 30 and 60 seconds, and each wait is different. It spreads your requests out and is gentler on the site.

Add a stop so it never runs forever

Use refresh limits to stop after a time or a number of refreshes, and turn on the on-page countdown so you can see the next reload coming.

Good to know

Questions, answered.

Can I refresh every second?

Yes, one second is the minimum. Use it only briefly, because many sites dislike it.

What interval should I use for a stock or price page?

One to two minutes is plenty for most pages, and kinder to the site.

Does the interval change per tab?

Yes. Each tab keeps its own timer.
