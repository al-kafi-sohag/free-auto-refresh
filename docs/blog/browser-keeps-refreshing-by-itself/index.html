Troubleshooting

Why your browser keeps refreshing by itself.

A page that reloads on its own is annoying, and it nearly always has a boring cause. Work down this list, easiest checks first.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

1. An extension is doing it

Refresh, monitor, ad blocker and shopping extensions can all reload pages. Open a private window, where extensions are off by default. If the reloading stops, switch extensions off one at a time to find it.

2. Chrome unloaded the tab

Chrome's Memory Saver puts unused tabs to sleep and reloads them when you come back. It looks like the page refreshed itself. Turn it off in Settings, Performance, or add the site to the always-active list.

3. The website refreshes on purpose

News, scores, dashboards and webmail often reload using a refresh tag or a script. This is by design. Look for a pause or "live updates" switch on the page.

4. The tab crashed and recovered

If you briefly see an "Aw, Snap" or error page before the content comes back, the tab ran out of memory. Close other tabs, and check for a heavy page or extension.

5. A stuck F5 key

It sounds silly, but a sticky or held F5 or Ctrl key reloads the page repeatedly. Try the on-screen keyboard, or unplug and replug an external keyboard.

6. A login or Wi-Fi redirect

Hotel or café Wi-Fi often redirects you to a sign-in page, which looks like a refresh. Open a plain http address to trigger the sign-in page and complete it.

7. Adware or a hijacked browser

If pages reload and redirect to unknown sites, check your extensions and search settings, and run a malware scan. Remove anything you do not recognise.

8. A refresh you started and forgot

If you used an auto refresh tool earlier, it may still be running. Click its icon and press Stop. With Free Auto Refresh you can also press Alt + Shift + R, or set a limit so it stops by itself next time.

Good to know

Questions, answered.

How do I stop a website from refreshing itself?

Firefox can block it with accessibility.blockautorefresh in about:config. Chrome has no built-in switch. See our full guide on stopping auto refresh.

Why does my tab refresh when I switch back to it?

That is usually Memory Saver or tab sleeping. Turn it off in the browser's performance settings.

Could it be a virus?

Rarely. If it also redirects you to strange sites, scan for malware and remove unknown extensions.
