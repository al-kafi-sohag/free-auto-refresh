This page refreshes automatically. Now what?

A short message says the site is busy and the page will reload by itself. In most cases the best thing you can do is nothing at all.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

What the message is telling you

The site has built the reload into the page. A script or a refresh instruction will try again after a short delay, so you do not need to press anything. You often see it on waiting rooms, queue pages, busy shops, ticket sales, results pages and status screens.

Why you should usually leave it alone

  • On some queues, a manual reload can send you to the back of the line.
  • Extra reloads add load to a site that is already struggling.
  • Opening many tabs or running another refresh timer can look like a bot and get you blocked.

Read any instructions on the page first, and follow them over general advice, including ours. Do not add an auto refresh extension to a waiting room.

When something is actually stuck

If the same message stays for much longer than the page suggests, check the company's official status page or social account. If the site works for others, try one reload, then check that JavaScript and cookies are allowed for it, since queue pages often need both. As a last step, try again later.

If the page does not refresh itself

Some pages never update on their own, such as a basic status or listing page. For those, a calm timer helps. Free Auto Refresh reloads a tab at the interval you choose, and page watching can stop and notify you when certain text appears. Pick a long interval and respect the site's rules. Good to know

Questions, answered.

Should I press F5 to speed it up?

Usually no. It does not move you forward and on some queues it can reset your place.

Is the message a sign of malware?

A plain waiting message on a site you meant to visit is normal. Be wary if it asks you to install something, run a command or enter payment details to skip the wait.
