Auto refresh in Opera and Opera GX.

Opera has its own add-ons store, but it can also run Chrome extensions once you add a helper. After that, auto refresh works like in Chrome.

Add to Chrome Add to Firefox

Step 1: add the helper

In Opera, open the add-ons store and install Install Chrome Extensions. It lets Opera add extensions from the Chrome Web Store.

Step 2: install the extension

  1. Open the Free Auto Refresh page and click Add to Chrome.
  2. On the Chrome Web Store page, click the button that now reads Add to Opera.
  3. Pin the extension from the extensions menu.

Step 3: start the timer

Open any page, click the icon, set an interval and press Start. Opera GX works the same way.

Opera GX limits and background tabs

Opera GX has a limiter for RAM and CPU and can put background tabs to sleep. If a refreshing tab stops reloading while hidden, keep that tab visible or exempt it in GX Control.

Questions, answered.

Does Opera GX support Chrome extensions?

Yes, once you install the Install Chrome Extensions add-on.

Is there an Opera-only version?

No. The Chrome version is the one to use.

Why does my Opera tab stop reloading?

Background tab sleeping or the GX limiter. Keep the tab visible or exempt it.
