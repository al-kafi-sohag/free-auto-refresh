Use cases

See new freelance projects while they are fresh.

On many marketplaces the first few proposals get the most attention. If the feed has no instant alert you like, a watched tab can tell you the moment a new project lands.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

Set the feed to newest first

Filter the project feed by your skills and budget, then sort it by newest. New items should show at the top. Open that page in a tab.

Set up the watch

  1. Open the feed and the Free Auto Refresh popup.
  2. Under Advanced settings, Watch the page, choose Stop when the page changes.
  3. If sponsored items change constantly, point it at the list with a CSS selector.
  4. Use 2 to 5 minutes, with a random range such as 120 to 300 seconds, and press Start.

You get a desktop notification and a flashing tab title on a change.

Skip the manual reloads

Write the proposal yourself

Speed helps, but a short, specific proposal that shows you read the brief beats a generic one sent first. The extension does not write, send or apply for you. It only tells you something is new.

Check the marketplace's rules

Some marketplaces limit automated page loading or require you to use their own alerts. Read the terms, keep the interval long, and prefer the site's built-in notifications where they exist. See refreshing politely.

Good to know

Questions, answered.

Will it apply to projects for me?

No. It only alerts you; you read the brief and send the proposal yourself.

How often should it check a project feed?

Every 2 to 5 minutes is enough. Faster adds little and may get you limited.

Does it work when I am signed in?

Yes, it reloads the page you have open. If the site signs you out after a while, sign in again when you are alerted.
