Shortcuts

Start and stop auto refresh from the keyboard.

You do not need to open the popup each time. One shortcut starts or stops the timer on the tab you are on, which is handy when you are about to type a bid or fill a form.

The default shortcut

Press Alt + Shift + R to start or stop auto refresh on the current tab. It uses the settings you last chose in the popup, so set your time once and then toggle with the keys.

Change the shortcut in Chrome

  1. Open chrome://extensions/shortcuts in a new tab.
  2. Find Free Auto Refresh, and click the box next to "Start / stop auto refresh on the current tab".
  3. Press the keys you want.

Chrome needs at least Ctrl or Alt in the combination.

Skip the manual reloads

Free Auto Refresh reloads a tab on a timer and can alert you when a page changes. Free, private, no account.

Change it in Firefox

Open about:addons, click the gear icon, and choose Manage Extension Shortcuts. Then set a new key for Free Auto Refresh.

Good times to use it

  • Stop the timer when you are about to type a bid or a message.
  • Start it again when you step away.
  • Pause a page that you want to read for a while without losing your settings.

If you often forget, Smart pause can hold the reload while you type.

Good to know

Questions, answered.

What if Alt + Shift + R does not work?

Another extension or app may be using the same keys. Change the shortcut on the extension shortcuts page.

Does the shortcut work on every tab?

It acts on the tab you are on, and you can use it on any normal web page. Browser pages like the new tab page do not allow it.

Does it work on Mac?

Yes, though the default keys can differ. Check and set the key on the shortcuts page of your browser.
