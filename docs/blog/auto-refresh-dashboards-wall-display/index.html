Keep a dashboard fresh on its own.

A sales board or support queue on a wall screen is only useful if it is current. Many dashboards do not reload themselves, or reload too slowly. A refresh timer fixes that in a minute.

Al Kafi SohagNov 19, 20262 min read
Add to Chrome Add to Firefox

Check the built-in refresh first

Tools such as Grafana, Looker Studio and Power BI have their own refresh settings, and they use less data than reloading the whole page. If yours has one, use it. Use a browser timer when the tool has no refresh option, when it is slower than you need, or when the page is a simple internal web page.

Setting it up

  1. Open the dashboard in its own browser window.
  2. Open Free Auto Refresh and set the time, for example 60 seconds in Min and Max.
  3. Turn on Keep scroll position if the board is long.
  4. Press Start and put the window in full screen with F11.

Choose a sensible time

  • A queue people act on: 30 to 60 seconds.
  • A sales or finance board: 5 to 15 minutes.
  • A server status board: 30 to 60 seconds.

Remember that each reload is a request to the dashboard's server, and some reports are costly to run. Do not go faster than people read it.

Keep it running

Turn on Keep the tab awake so the browser does not put it to sleep. With saved profiles you can keep one set of settings per screen. The option to remember a page lets a page you started begin refreshing again when it is reopened, including after a browser restart.

Know the limits

A reload can sign the page out if the tool's session expires, and the screen will show a sign-in page until someone signs in. For an unattended display, use an account and a session length meant for it, within your company's rules.

Good to know

Questions, answered.

Does it work on a screen nobody touches?

Yes, if the page stays signed in. Turn on Keep the tab awake and choose a time that suits the data.

Is reloading the page worse than the tool's own refresh?

Usually yes: it loads the whole page again. Use the built-in refresh when there is one.

Can it restart after the browser is closed?

With Remember this page turned on, a page you started refreshes again when it is opened, until you press Stop.
