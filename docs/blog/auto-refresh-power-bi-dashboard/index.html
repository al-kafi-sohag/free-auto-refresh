How-to

Keep a Power BI screen current.

The key idea: reloading the browser can only show data Power BI already has. Getting new data is a separate step.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Two different kinds of refresh

  • Data refresh brings new data from the source into your model.
  • Visual or page refresh updates what is shown on screen.

If the model has not been updated, no amount of reloading will show newer numbers.

Scheduled refresh for imported data

For imported data, publish the report and set up scheduled refresh in the semantic model's settings in the Power BI service. How often you can run it depends on your licence and capacity, and some sources need a gateway. Check Microsoft's current limits.

Automatic page refresh

Power BI has an automatic page refresh feature for supported live connections such as DirectQuery. You turn it on in the page's formatting settings. The shortest interval you may use can be limited by your administrator and capacity, and it is not available for every kind of data.

Reload the browser on a wall display

If a screen needs an occasional full reload, for example to pick up the latest published view, a browser timer can do it. Open the report, switch it to full screen, and set Free Auto Refresh to an interval such as 15 or 30 minutes. A reload may reset filters, page choice or full-screen mode, so test it once while you are there. It does not trigger a data refresh.

Before you leave it running

Set the computer not to sleep, keep the tab active, and expect the sign-in to expire at some point. Follow your organisation's security rules for unattended screens and use an account meant for that purpose.

Good to know

Questions, answered.

Will reloading the page update my data?

Only if newer data is already available to the report. It does not run a scheduled data refresh.

Why can't I find automatic page refresh?

It depends on your data connection, and your administrator or capacity settings can restrict it.

Can a browser extension refresh Power BI Desktop?

No. An extension works only inside the browser, not in the desktop application.
