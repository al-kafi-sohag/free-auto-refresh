Auto refresh in Microsoft Edge.

Edge is built on the same engine as Chrome, so Chrome extensions install and run in it. That makes auto refresh a two-minute job.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

Install it in Edge

  1. Open the Free Auto Refresh page and click Add to Chrome. It opens the Chrome Web Store.
  2. If Edge shows a banner, choose Allow extensions from other stores.
  3. Click Add to Edge, then confirm.

Start refreshing

  1. Open the page you want to reload.
  2. Click the extensions icon, then pin Free Auto Refresh to the toolbar.
  3. Pick an interval and press Start.

Skip the manual reloads

Free Auto Refresh reloads a tab on a timer and can alert you when a page changes. Free, private, no account.

Edge-specific things to know

  • Sleeping tabs: Edge can put inactive tabs to sleep. If a refreshing tab is not reloading in the background, add it to the never-sleep list in Settings, System and performance.
  • Kiosk mode: for a wall dashboard, a timer on the single open tab is simpler than scripting.

Useful extras

You can watch for a word and get a notification, or show a countdown on the page so you know when the next reload is.

Good to know

Questions, answered.

Can I use Chrome extensions in Edge?

Yes. Edge accepts extensions from the Chrome Web Store once you allow other stores.

Does Edge have a built-in auto refresh?

No. Use an extension.

Why does my Edge tab stop refreshing?

Sleeping tabs. Add the site to the never-sleep list in Edge's performance settings.
