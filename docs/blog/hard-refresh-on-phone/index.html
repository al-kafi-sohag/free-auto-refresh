Shortcuts

Hard refresh on your phone.

On a computer a keyboard shortcut does it. Phone browsers do not give you the same button, so you use one of a few workarounds. Start with the gentlest.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

1. Reload, then try a private tab

Reload using the circular arrow or by pulling down on the page. If it still looks old, open the same address in a private or incognito tab. It starts without your saved site data, so it is a quick way to see whether your saved copy is the problem.

2. iPhone and iPad

  • To remove one site's data: open Settings, find Safari (under Apps on newer versions), then Advanced > Website Data, and delete that site.
  • With a hardware keyboard on an iPad, Cmd + R reloads the page.
  • Clear History and Website Data also works, but it affects every site and signs you out of many. Use it last.

3. Android with Chrome

  • For one site: open it, tap the icon next to the address, and look for the cookies and site data options to delete them.
  • For all sites: open Chrome's menu, choose to delete browsing data, and select only cached images and files. That usually keeps you signed in.

Menus differ between versions and phone makers.

4. A trick for testing your own page

Add a harmless query to the end of the address, such as ?v=2. Many caches treat it as a new address. It only affects the page address, so scripts and images on the page may still be cached. Developers should version those file names too.

Good to know

Questions, answered.

Is there a hard refresh button in Safari on iPhone?

No dedicated button does the same job as the desktop shortcut. A private tab or deleting the site's data are the practical alternatives.

Is a hard reset the same thing?

No. A hard or factory reset affects the whole phone and can erase it. It has nothing to do with refreshing a page.

Why does the page still look old?

The website or a network cache may still be sending the old version. Check on another device or try later.
