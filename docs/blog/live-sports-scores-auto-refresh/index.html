Keep live scores up to date.

Many score pages update themselves, but plenty of league tables, school fixtures and club pages do not. A reload on a timer makes sure the number you see is the number that is real.

Al Kafi SohagNov 19, 20262 min read
Add to Chrome Add to Firefox

Check if the page needs it

Watch the score for a minute. If it changes without you doing anything, the page already updates itself and does not need a timer. If it stays still while the game moves on, a timer will help.

Set a sensible time

  • Live match page: 15 to 30 seconds.
  • League table: 1 to 5 minutes. It changes only when a game ends.
  • Fixtures and results: 5 to 15 minutes.

Use the same number in Min and Max for a steady beat, or a range for a gentler pattern.

Be told when the score changes

You do not have to watch the screen. Use page watching on the score element and choose Stop when the page changes. A desktop notification tells you when it moves.

Put it on a second screen

Open the page in its own window, turn on the on-page counter to see when the next refresh is due, and add a limit of a couple of hours so it stops after the game.

Use the official live view when you can

Official apps and live pages send updates faster than reloading a whole page. A timer is for the pages that have no live view. Do not use it for anything that needs instant data, such as placing bets.

Good to know

Questions, answered.

How often should I refresh a live match page?

Every 15 to 30 seconds is usually enough, and kinder to the site than every few seconds.

Will it tell me when someone scores?

Use page watching on the score. It notifies you when the page changes.

Is it good for betting?

No. A reload every few seconds is not real-time data. Do not rely on it for decisions that depend on speed.
