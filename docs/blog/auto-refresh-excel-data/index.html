Auto refresh Excel data.

Excel has its own refresh settings, and for desktop workbooks they are the right tool. A browser extension is not needed for that.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Refresh a connection every few minutes

  1. In desktop Excel, open the Data tab and then Queries & Connections.
  2. Right-click your query or connection and choose Properties.
  3. Tick Refresh every and set the number of minutes.
  4. Optionally tick Refresh data when opening the file.

Not every connection type offers every option, and the workbook must be open.

Pivot tables

A pivot table does not always update the moment its source changes. Right-click it and choose Refresh, or use Refresh All on the Data tab. In PivotTable Options, on the Data tab, you can refresh when the file opens. Some newer Microsoft 365 versions also offer an automatic refresh setting for pivot tables.

Faster than every minute?

The built-in timer works in minutes. For shorter intervals people use a VBA macro with Application.OnTime. Only run macros you understand and trust, and do not hit an outside data source more often than its rules allow.

Excel in the browser

Excel for the web shows co-authors' edits without a manual reload. Reloading the tab is not the same as refreshing a data connection, and web Excel supports fewer connection types than the desktop app. Check Microsoft's current guidance for your data source.

Where a page timer does help

If your numbers are on an ordinary web report that never updates by itself, auto refresh can reload that page. For screens on a wall, see refreshing a dashboard display.

Good to know

Questions, answered.

Can Excel refresh when the file is closed?

The in-app timer needs the workbook open. Unattended updates need another tool or service that supports your data.

Why is Refresh every greyed out?

The option depends on the type of connection and how it was created.

Does auto refresh slow Excel down?

Large queries refreshed often can. Use the longest interval that still meets your needs.
