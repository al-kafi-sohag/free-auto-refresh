Monitoring

Timer or watch: pick the right mode.

Free Auto Refresh can just reload a page, or reload it and tell you when something changes. They look alike but suit different jobs. Here is how to choose.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

Use a plain timer when

  • You are looking at the page and want it kept current: a dashboard, a score, a deploy status.
  • The page changes constantly and you want to see each change.

Set a time, press Start, and optionally add a limit. See how to pick the time.

Use page watching when

  • You are waiting for one thing to happen: an item back in stock, a slot opening, a result appearing.
  • You want to do something else until it does.

Under Advanced settings, Watch the page, choose a mode and the extension stops and notifies you when it matches.

Which watch mode?

  • Stop when text appears: you know the words that will show up, such as In stock.
  • Stop when text disappears: you know the waiting message, such as Sold out or Processing.
  • Stop when the page changes: you do not know the words. Point it at one area with a CSS selector to avoid false alarms.
Text matching ignores upper and lower case.

Use both for long waits

A watch with a random interval of one to five minutes and a time limit covers most waits. Save it as a profile so the next wait is one click.

Good to know

Questions, answered.

Does page watching read my private pages?

It reads only the visible text in your own browser, and the comparison happens locally. Nothing is sent anywhere.

What happens when the watch matches?

Refreshing stops, you get a desktop notification and the tab title flashes.

Which mode is best for restock alerts?

Stop when text appears, using words like In stock or Add to cart, or stop when Sold out disappears.
