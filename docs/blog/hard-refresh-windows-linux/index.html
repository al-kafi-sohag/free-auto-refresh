Shortcuts

Hard refresh on Windows and Linux.

One shortcut covers nearly every browser on Windows and Linux. Here it is, with the exceptions, and what to do on a phone where no shortcut exists.

Add to Chrome Add to Firefox

The shortcut

Press Ctrl + F5 or Ctrl + Shift + R. Either one reloads the page and ignores the cached files for it.

By browser

  • Chrome: Ctrl + F5 or Ctrl + Shift + R
  • Firefox: Ctrl + F5 or Ctrl + Shift + R
  • Edge: Ctrl + F5 or Ctrl + Shift + R
  • Brave and Opera: Ctrl + F5 or Ctrl + Shift + R

Prefer the mouse? Hold Shift and click the reload button.

Chromebook

ChromeOS uses Ctrl + Shift + R. The refresh key on the top row is a normal reload.

Android and iPhone

Phones have no hard refresh shortcut. The nearest thing is to clear the site's saved data. In Chrome for Android, open Settings, Privacy and security, Delete browsing data and clear cached images and files. In Safari on iPhone, go to Settings, Safari, Advanced, Website Data.

When a laptop ignores F5

If your function keys control brightness or volume, hold Fn as well, or just use Ctrl + Shift + R.

Want it automatic?

If you keep hard refreshing a page to see when something changes, let the timer do it. Free Auto Refresh for Chrome and for Firefox both include a cache-bypassing reload.

Good to know

Questions, answered.

Is Ctrl+F5 the same as Ctrl+Shift+R?

Yes, in all the major browsers they both force a reload without cached files.

How do I hard refresh on Android?

There is no shortcut. Clear cached images and files in Chrome's browsing data settings.

Does a hard refresh work in Firefox on Linux?

Yes. Ctrl + Shift + R or Ctrl + F5 works the same way.
