Use cases

Be first to see a new listing.

Good flats, bikes and cars go in hours. Classified and marketplace sites often only email you later. If the search page is open in a tab, it can tell you the moment something new is at the top.

Al Kafi SohagNov 19, 20262 min read
Add to Chrome Add to Firefox

Build the right search first

Set your filters (price, area, size) and sort by newest. Open that results page. Everything below depends on new items appearing at the top of the list.

Set up the watch

  1. Open the sorted results page and the Free Auto Refresh popup.
  2. Under Advanced settings, Watch the page, choose Stop when the page changes.
  3. If sponsored items keep changing, choose the results list with a CSS selector so only the real listings count.
  4. Set 3 to 10 minutes, or a random range like 180 to 300 seconds, and press Start.

Skip the manual reloads

Free Auto Refresh reloads a tab on a timer and can alert you when a page changes. Free, private, no account.

Check the site's rules first

Some marketplaces do not allow automated loading of their pages, and heavy refreshing can get an account limited. Read the terms, keep the interval long, and use the site's own saved-search email alerts when they exist. This extension is meant for the pages that have none.

Reduce false alerts

  • Watch only the listing area, not the whole page.
  • Use a saved profile per search, so the settings are one click away.
  • Add Smart pause so a reload never interrupts you writing to a seller.

What it does not do

It does not message sellers, make offers or buy anything. It tells you a page changed, and you act. For stock of one product, see back-in-stock alerts.

Good to know

Questions, answered.

Will it message the seller for me?

No. It only alerts you, and you reply yourself.

How often should it check?

Every 3 to 10 minutes. Faster does not help and can get you limited.

Does it work on Facebook Marketplace?

It works on any page you open, but dynamic pages can change for other reasons, so watch just the results list.
