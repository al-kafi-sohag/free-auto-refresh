Normal, hard, or empty cache and hard reload?

Chrome offers three ways to reload a page, and they are not the same. Here is what each one asks the browser to do, and which to pick.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

Normal refresh

Press F5 or Ctrl + R (Command + R on a Mac). The browser asks the site if its files changed, and reuses saved copies when the answer is no. It is fast, and sometimes shows stale content.

Hard refresh

Press Ctrl + F5 or Ctrl + Shift + R (Command + Shift + R on a Mac). The browser skips its saved copies for that page and downloads everything again. Use this when a page looks old or a fix you just made is not showing.

Empty Cache and Hard Reload

This option only appears in Chrome when DevTools is open. Press F12, then right-click (or click and hold) the reload button next to the address bar and choose Empty Cache and Hard Reload.

It clears the cached files for the page and then reloads. It goes one step further than a hard refresh, because it also drops copies that a hard refresh can leave behind.

Which one should you use?

  • Page looks fine: normal refresh.
  • Page looks outdated: hard refresh.
  • Still wrong after a hard refresh: Empty Cache and Hard Reload.
  • Still wrong after that: the problem is probably on the website's side, not in your browser.

Does any of this delete my data?

No. None of the three options removes passwords, cookies or history. Only the page's cached files are affected.

Good to know

Questions, answered.

Why is Empty Cache and Hard Reload missing?

It only shows when Chrome's DevTools is open. Press F12 first, then right-click the reload button.

Is a hard refresh the same as clearing the cache?

Not quite. A hard refresh bypasses the cache for one page load. Clearing the cache deletes saved files for the whole browser.

Does a hard refresh work in Firefox?

Yes. Ctrl + F5 or Ctrl + Shift + R (Command + Shift + R on a Mac) does the same job.
