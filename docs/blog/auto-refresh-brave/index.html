Auto refresh in Brave.

Brave is Chromium-based and installs extensions from the Chrome Web Store directly, so auto refresh works the same as in Chrome.

Add to Chrome Add to Firefox

Install it in Brave

  1. Open the Free Auto Refresh page and click Add to Chrome.
  2. Brave opens the Chrome Web Store page. Click Add to Brave and confirm.
  3. Pin it from the puzzle-piece menu.

Set the timer

Open the page, click the icon, choose an interval from 5 seconds to 5 minutes or type your own, and press Start. The first reload happens straight away.

Brave Shields and refreshing

Brave Shields block ads and trackers on a page. They do not stop a tab from reloading on a timer, so no special setting is needed. If a site breaks, you can lower the Shields for that site without affecting the extension.

Memory and background tabs

Like Chrome, Brave can free memory from tabs you are not using. If a background tab stops reloading, keep it open and active in its own window.

Questions, answered.

Does Brave support Chrome extensions?

Yes. It installs them from the Chrome Web Store.

Does Brave Shields block auto refresh?

No. Shields block ads and trackers, not page reloads.

Is it private?

Yes. The extension has no analytics and sends nothing to a server.
