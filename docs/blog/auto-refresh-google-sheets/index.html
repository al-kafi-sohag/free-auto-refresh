Does Google Sheets need auto refresh?

Often it does not. First work out what you are waiting for: someone's edit, a formula, or data from outside the sheet.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Edits from other people

When your connection is working, changes made by collaborators appear in the open sheet on their own. If yours seems stuck, check the offline indicator and then reload once.

Time-based formulas

For functions such as NOW() and RAND(), open File > Settings > Calculation. Set recalculation to On change and every minute or every hour if you need them to update without edits.

Imported and finance data

Functions such as IMPORTRANGE, IMPORTHTML and GOOGLEFINANCE update on Google's own schedule. They are not instant, and finance data can be delayed. Reloading the tab does not promise newer results.

Scheduled updates with Apps Script

To run a task on a schedule even when the sheet is closed, open Extensions > Apps Script, write a function that does the update, and add a time-driven trigger. Google applies daily quotas, so keep the schedule modest and only authorise scripts you trust.

When reloading the tab makes sense

A reload can help on a published, view-only version of a sheet shown on a screen, which may not update itself promptly. Published pages can lag behind the original, so test it. Use auto refresh with an interval of a few minutes. Avoid timers on a sheet you are editing, because they can interrupt your typing.

Good to know

Questions, answered.

Can Sheets update every second?

The built-in recalculation options are far slower than that, and import functions have their own schedule.

Does auto refresh reload imported data?

Not necessarily. Imported data follows Google's caching and update rules.

Will a script run when my computer is off?

A time-driven Apps Script trigger runs on Google's servers, so it does not need your computer.
