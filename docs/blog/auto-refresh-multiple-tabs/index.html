How-to

Auto refresh several tabs, each at its own speed.

A restock page, a dashboard and a status page do not need the same timing. Here is how to run a timer on each tab, and keep it from turning into a mess.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

One timer per tab

Free Auto Refresh runs on the tab you start it on. Open the first page, set its time and press Start. Then switch to the next tab and do the same with different numbers. The tabs do not share a timer, so one can reload every 10 seconds while another waits 5 minutes.

Alt + Shift + R starts or stops the timer on the tab you are looking at.

Save a profile for each job

Typing the same numbers each time is slow. In the popup, open All settings, name the current set-up under Profiles and save it. You can keep up to 50. Next time, pick the profile from the menu at the top of the popup. Read more about saved profiles.

Pick sensible speeds

  • Pages you are actively watching: 10 to 30 seconds.
  • Pages that only need to be current when you look: 1 to 5 minutes.
  • Pages you want to be told about: use page watching and a slower timer.

Do not overload one site

Ten tabs on the same site reload ten times as often. Use a random range, such as 40 to 80 seconds, and a time limit. See how to refresh without getting blocked.

What it does not do

There is no single button that refreshes every open tab at once, and no shared timer across tabs. You start each tab yourself, which keeps you in control of what reloads.

Good to know

Questions, answered.

Can I refresh all my tabs with one click?

Not with one shared timer. Start the timer on each tab you want reloaded; profiles make that quick.

Do the tabs reload at the same moment?

Only if you give them the same fixed time. Random ranges spread them out.

Will many timers slow Chrome down?

Reloading many heavy pages does. Keep intervals long and the number of tabs small.
