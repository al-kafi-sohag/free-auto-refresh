Clear cache for one website only.

One site is acting up and you do not want to be signed out of everything else. Here is how to deal with just that site, and the lighter option to try first.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Try a hard refresh first

If the page only looks out of date, you may not need to delete anything. A hard refresh asks the browser to download the page again instead of using its saved copy.

  • Windows, Linux, ChromeOS: Ctrl + Shift + R (Ctrl + F5 also works in many browsers).
  • Mac, Chrome or Firefox: Cmd + Shift + R.
  • Mac, Safari: Option + Cmd + R.

It affects only the page you are on and keeps you signed in. The hard refresh guide has more shortcuts.

Chrome: delete one site's data

  1. Open chrome://settings/content/all.
  2. Type the site name in the search box.
  3. Click the delete (bin) button next to that site and confirm.

This removes that site's cookies and stored data, so you will probably be signed out of it. If you have developer tools open (F12), you can also go to the Application tab, choose Storage and press Clear site data.

Edge and Firefox

  • Edge: open Settings, search for cookies, open the list of all cookies and site data, find the site and delete it.
  • Firefox: open the site, click the icon to the left of the address, and choose Clear cookies and site data.

Menu names move between versions, so use the search box inside Settings if you do not see them.

Safari on Mac, iPhone and iPad

  • Mac: Safari > Settings > Privacy > Manage Website Data. Search for the site and press Remove.
  • iPhone or iPad: open Settings, find Safari (under Apps on newer versions), then Advanced > Website Data. Swipe left on the site to delete it.

What you lose, and what does not help

Deleting site data can sign you out and reset that site's preferences, such as language or a saved cart. Passwords saved in your browser's password manager stay. The usual Clear browsing data window is different: it works by time range, so it affects every site you visited in that period.

If you are building a site and keep seeing old files, hard reload on every refresh saves you from clearing anything by hand.

Good to know

Questions, answered.

Can I clear only the cache and keep cookies for one site?

Browser settings usually delete a site's data as a group. A hard refresh is the easiest way to get fresh files for one page while staying signed in.

Will this delete my saved passwords?

No. Passwords saved in the browser's password manager are stored separately, although you may have to sign in again.

What if the page is still old afterwards?

The website or a network cache may still be serving the old version. Try a private window, another device, or wait a little.
