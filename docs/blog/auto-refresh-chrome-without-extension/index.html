Auto refresh Chrome without an extension.

Chrome has no timer for reloading a tab. A few tricks exist, but most of them break after the first reload. Here is what actually works.

Al Kafi SohagNov 18, 20262 min read
Add to Chrome Add to Firefox

The built-in option: none

No setting in Chrome, Edge or Firefox repeats a reload for you. Everything below is a workaround.

Workaround 1: the DevTools console

Press F12, open Console and paste setInterval(() => location.reload(), 30000). The catch: the page reloads once, and the script is wiped by the reload, so it never fires again. It is a one-time reload, not a loop.

Workaround 2: a local page with a meta refresh

You can save a small HTML file containing a meta refresh tag and an iframe pointing at the page. It repeats, but many sites forbid being shown in an iframe, so it only works for some pages. You also lose the normal tab, login and scroll behaviour.

Workaround 3: a bookmarklet

A bookmarklet runs once when you click it. For the same reason as the console, it cannot keep a timer alive across reloads.

Why an extension is the reliable answer

An extension keeps its timer outside the page, so reloading the page does not reset it. Free Auto Refresh is free, needs no account and keeps a separate timer for every tab. It adds word and change alerts and limits that the workarounds cannot match.

Good to know

Questions, answered.

Can I auto refresh a tab with a Chrome setting?

No. Chrome has no built-in auto refresh.

Why does the console trick only reload once?

Reloading the page destroys the script, including its timer.

Is it safe to install a refresh extension?

Check what permissions it asks for and whether it collects data. Free Auto Refresh has no analytics and no account.
