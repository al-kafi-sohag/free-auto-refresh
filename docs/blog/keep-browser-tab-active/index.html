How-to

Keep an important tab awake.

Browsers save memory by putting idle tabs to sleep. That is great until the sleeping tab is the one you are waiting on. Here is how to protect it.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Chrome: add the site to Memory Saver exceptions

  1. Open chrome://settings/performance.
  2. Find the list of sites to always keep active.
  3. Add the site you want to protect.

You can also turn Memory Saver off, but an exception keeps the memory savings for everything else.

Edge: sleeping tabs

  1. Open Edge Settings and search for sleeping tabs.
  2. Under the list of sites that never sleep, add your site, or turn sleeping tabs off.

Firefox and other browsers

Firefox can unload tabs when your computer is very low on memory. Closing heavy tabs and apps is the simplest protection. Brave, Opera and other Chromium browsers have their own memory or performance pages with similar options.

Do not forget the computer itself

No browser setting helps if the computer goes to sleep. For a long watch, set your power options so the machine stays awake while plugged in, and lock the screen when you walk away. A closed laptop lid usually puts the computer to sleep too.

With auto refresh running

Free Auto Refresh has a Keep the tab awake option that asks the browser not to put a refreshing tab to sleep. It is a request, not a guarantee, and the browser can still unload tabs when memory is critically low. Timers in background tabs can also run about a second late. Use it together with the exception above.

Good to know

Questions, answered.

Does pinning a tab keep it active?

Pinning keeps a tab easy to find. Do not rely on it to prevent sleeping; add a site exception.

Will auto refresh work while I use another tab?

Yes, a tab with a running timer keeps refreshing in the background as long as the browser keeps it loaded and the computer is awake.

Can this keep me marked as online on a website?

Not reliably. Many sites judge activity by what you do, not by whether the tab is loaded.
