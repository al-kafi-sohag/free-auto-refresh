F5 not refreshing? Start here.

On many laptops the F5 key does something else by default, such as changing brightness. The good news is that you have other ways to refresh.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

Use a shortcut that works right now

  • Windows and Linux: Ctrl + R reloads. Ctrl + Shift + R does a hard refresh.
  • Mac: Cmd + R reloads. In Chrome and Firefox, Cmd + Shift + R does a hard refresh.
  • Any computer: click the circular arrow next to the address bar.

Laptops: the Fn key

  1. Hold Fn and press F5. For a hard refresh, try Fn + Ctrl + F5.
  2. To swap the default, look for Fn Lock, often on the Esc key. The combination differs by maker.
  3. Some computers have a function key setting in the BIOS or in the maker's utility app.

Mac keyboards

F5 is not the normal refresh key on a Mac. Use Cmd + R. See the Mac hard refresh shortcuts.

If F5 fails only in the browser

  • An extension may have taken over the key. Test in a private window.
  • Some web apps and games use F5 for their own commands. Click the address bar first, then try again.
  • A keyboard utility or macro app may be remapping it.

If F5 fails in every program, test another keyboard and restart the computer.

Good to know

Questions, answered.

Is Ctrl+R the same as F5?

In common desktop browsers, both do a normal reload.

Why does F5 change brightness or volume?

Your keyboard's top row is set to media actions first. Hold Fn or change Fn Lock to get the F key.

Does Shift + F5 hard refresh?

In Chrome on Windows it reloads while ignoring the cache, like Ctrl + F5. Behaviour can differ in other browsers.
