How-to

Auto refresh, then stop by itself.

The easiest mistake with an auto refresh is forgetting it. A tab left reloading overnight wastes data and annoys the site. A limit fixes that in two clicks.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

Two kinds of limit

  • Stop after (minutes): ends the run when the time is up. Good for events with a clock, such as a sale, a match or a working day.
  • Max refreshes: ends it after a number of reloads. Good for keeping the total number of requests to a site small.

Use both, and whichever is reached first wins. Leave both at 0 for no limit.

How to set a limit

  1. Open the popup and go to Advanced settings, Limits.
  2. Type minutes into Stop after, or a number into Max refreshes.
  3. Press Start.

The popup shows the time left, and the on-page counter says why it stopped. Click the pin next to a limit to keep it on the main view.

Examples

  • A two-hour flash sale: Stop after 120 minutes.
  • Checking a results page: Max refreshes 100.
  • A restock watch overnight: a time limit plus a watch rule that stops on the first match.

Other ways a run ends

A run also ends when you press Stop or Alt + Shift + R, or when a watch rule finds what it is looking for.

Good to know

Questions, answered.

What happens when the limit is reached?

Refreshing ends and the counter on the page tells you which limit stopped it.

Can I use a time limit and a count limit together?

Yes. Whichever comes first ends the run.

Does closing the tab also stop it?

Yes. The timer belongs to the tab, so closing the tab ends it.
