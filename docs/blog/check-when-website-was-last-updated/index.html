Monitoring

When was this page last updated?

No single method works on every site. Check two or three of these and see whether they agree.

Al Kafi SohagNov 27, 20262 min read
Add to Chrome Add to Firefox

1 and 2: look at the page and the sitemap

First look near the headline or at the bottom for Updated or Published. A copyright year in the footer is not an update date.

Next, try adding /sitemap.xml to the domain. Many sitemaps list a lastmod date for each address. It is only as accurate as the site makes it.

3: the Wayback Machine

Paste the address into the Internet Archive's Wayback Machine. If it has saved copies, you can compare them and see roughly when something changed. It does not capture every page or every change, so the dates give you a range, not an exact moment.

4: document.lastModified

Open the page, press F12, choose the Console tab, type this and press Enter:

document.lastModified

Be careful: many modern pages are generated when you visit them, and then this simply shows the current time. If the answer is the time right now, ignore it. Only ever type console commands that you understand.

5: server headers

In developer tools, open the Network tab, reload, select the first request and look for a Last-Modified response header. Many sites do not send it, and a rebuild can change it without any visible edit.

Know about the next change

These methods look backwards. To catch a future change, page watching in Free Auto Refresh reloads the page on your timer, compares the visible content and notifies you when it changes. Good to know

Questions, answered.

Can I find the exact date of the last change?

Only if the site publishes a reliable date. Otherwise you can usually only estimate it.

Is the date in search results accurate?

It is a hint. Search engines work it out from the page and may not match the latest edit.

Can I get an email when a page changes?

Free Auto Refresh shows a desktop notification and does not send email. For email alerts, use an online monitoring service.
