Shortcuts

Hard refresh on Mac, browser by browser.

A normal reload can still show a saved copy of the page. A hard refresh skips that copy. On a Mac the shortcut is different for Safari than for everything else.

Add to Chrome Add to Firefox

The short answer

In Chrome, Firefox and Edge on a Mac, press Command + Shift + R. That reloads the page and ignores the cached files for it.

Safari is the odd one out. It has no single hard refresh key, so the steps are below.

Shortcut table

  • Chrome: Command + Shift + R
  • Firefox: Command + Shift + R (Shift + click on the reload button works too)
  • Edge: Command + Shift + R
  • Brave and Opera: Command + Shift + R
  • Safari: see the next section

Holding Shift while clicking the reload button in Chrome or Firefox does the same thing if you prefer the mouse.

Hard refresh in Safari on Mac

Safari hides the tools you need. Turn on the Develop menu once: open Safari, Settings, Advanced and tick Show features for web developers.

Then press Option + Command + E to empty the caches and press Command + R to reload. Two steps, but it does the same job as a hard refresh.

No Ctrl or F5 key on a MacBook?

You do not need them. Windows guides tell you to press Ctrl + F5, and MacBooks do not have an F5 key in the same place. Use Command + Shift + R instead, as above.

What a hard refresh does not do

It does not log you out, delete passwords or clear cookies. It only asks the website for fresh copies of its files for that one page. If a page still looks wrong after a hard refresh, the next step is Empty Cache and Hard Reload.

Good to know

Questions, answered.

What is the hard refresh shortcut for Chrome on a Mac?

Command + Shift + R. Shift + click on the reload button also works.

Is there a hard refresh in Safari?

Not as one key. Enable the Develop menu, press Option + Command + E to empty caches, then Command + R.

Will a hard refresh delete my cookies?

No. It only skips saved copies of the page's files. You stay signed in.
