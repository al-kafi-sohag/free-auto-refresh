Why Chrome reloads tabs you left.

You come back to a tab and it reloads, and whatever you were doing is gone. Before you blame a website or an extension, check this setting.

Al Kafi SohagNov 26, 20262 min read
Add to Chrome Add to Firefox

What Memory Saver does

To free up memory, Chrome can put tabs you have not used for a while to sleep. When you click one, Chrome has to load it again from the start. To you it looks like the page refreshed by itself, and a half-filled form or a video position can be lost.

How to tell it from auto refresh

  • It happens when you return to a tab, not on a fixed schedule.
  • It happens on tabs you left idle for a long time, usually in the background.
  • There is no countdown, and nothing in the page is asking to reload.

A page that reloads while you are looking at it is something else. See why a browser keeps refreshing by itself.

How to turn Memory Saver off

  1. Open chrome://settings/performance in a new tab.
  2. Turn off Memory Saver, or leave it on and add the sites you do not want put to sleep under the exceptions list.

Menu names can change between Chrome versions, so look for the Performance section if you do not see them.

Keep the tabs you are watching awake

If you are watching a page with a timer, keep that tab out of Memory Saver using the exceptions list. That way the tab keeps reloading on schedule and stays ready when you switch to it. Keep scroll position also saves your place on long pages.

Good to know

Questions, answered.

Is Memory Saver the same as auto refresh?

No. Memory Saver reloads a sleeping tab when you return to it. Auto refresh reloads on a timer.

Will turning it off use more memory?

It can, especially with many tabs open. The exceptions list lets you protect only the tabs that matter.

Can an extension cause tabs to reload?

Yes, an extension with a timer will, but only on tabs where you started it.
