Changelog

Every release, newest first.

Version 1.2.0

  • Remember this page: a page you started can start refreshing by itself when it is opened again, also after a browser restart
  • Quick presets you can edit: change the times, add your own, or remove the ones you never use
  • A list of remembered pages on the settings page

Version 1.1.0

  • Simpler popup, with advanced settings you can pin
  • 7 languages and a plain-language explanation on every setting
  • Waits for the page to load before checking it
  • Keep scroll position, pause on click or scroll, toolbar countdown, keep the tab awake
  • Profiles, export and import, and a full settings page

Version 1.0.0

  • First release: refresh timer, random intervals, page watching, smart pause, limits, on-page counter and notifications
